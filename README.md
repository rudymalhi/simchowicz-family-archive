# Simchowicz Family Archive

A self-contained multilingual static website in English, Hebrew, and German.

## Files

- `index.html` — page shell and metadata
- `styles.css` — responsive visual design
- `script.js` — translations, content, language switcher, and source filters

## Publish

Upload the three files to any static host. No build step or server is required.

Good options include:

1. GitHub Pages: create a repository, upload the files, then enable Pages from the repository settings.
2. Netlify: drag the `family-history-site` folder into Netlify Drop.
3. Cloudflare Pages: connect the repository or upload the folder as a direct deployment.

## Editorial and privacy notes

The public version intentionally does not publish current private addresses or profiles of living relatives. It labels direct documents, family-source entries, historical context, and research leads separately. Before publication, the family should review the names and fate entries in the spreadsheet and decide whether scanned documents should be made public.

## Research notes

The site records `Grenadierstraße 14` as the strongest documented Paula address. The earlier claim of No. 17 is not used as a fact. The possible identification of `Skarsicz` as Skarżysko-Kamienna remains explicitly marked as unconfirmed.
